# Bitácora de inteligencia artificial

## Consulta 1
- **Fecha:** 06/11/2026
- **Herramienta utilizada:** ChatGPT
- **Objetivo:** Crear una estructura HTML semántica para mi portfolio.
- **Prompt completo:** "Actuá como mentor de desarrollo web para una estudiante de sexto año. Ayudame a crear una estructura HTML5 para un portfolio personal con presentación, sobre mí, proyectos, habilidades y contacto. Usá etiquetas semánticas, no inventes información y explicá para qué sirve cada parte."
- **Parte utilizada:** Estructura general de `index.html`, navegación y secciones.
- **Cambios realizados por mí:** Revisar y completar las descripciones de mis proyectos con información real.
- **¿Qué comprendí?:** La función de `header`, `nav`, `main`, `section`, `article` y `footer`.
- **¿Qué descarté y por qué?:** Datos personales sensibles y afirmaciones sobre proyectos que todavía no confirmé.

## Consulta 2
- **Fecha:** 06/11/2026
- **Herramienta utilizada:** ChatGPT
- **Objetivo:** Crear un diseño inicial con CSS.
- **Prompt completo:** "Creá un CSS inicial para un portfolio estudiantil moderno y tecnológico, con azul oscuro, celeste y blanco. Usá CSS puro, variables de color, tipografía legible, tarjetas para proyectos y diseño adaptable a celulares. Explicá las reglas principales."
- **Parte utilizada:** Variables de color, estilos generales, tarjetas y adaptación para pantallas pequeñas.
- **Cambios realizados por mí:** Revisar colores, textos, espaciados y presentación en el navegador.
- **¿Qué comprendí?:** Cómo se aplican colores con variables, cómo se organizan tarjetas y cómo funciona una regla `@media`.
- **¿Qué descarté y por qué?:** Efectos y animaciones innecesarios para mantener un diseño simple.
